## 為什麼開這個部落格

東西寫下來才會留下。想法放在腦袋裡會忘，筆記散在各個 App 裡會找不到，所以決定集中到一個地方。

這裡會有三種內容：

- **日常** — 生活紀錄、想法、雜感。
- **技術** — 開發筆記、踩坑紀錄、工具心得。
- **作品** — 做出來的東西，附上說明與連結。

## 這個站怎麼做的

| 項目 | 用什麼 |
| --- | --- |
| 網站產生器 | Jekyll |
| 佈景主題 | Chirpy |
| 託管 | GitHub Pages |
| 部署 | GitHub Actions（push 後自動建置） |

寫文章的流程很單純：在 `_posts/` 新增一個 Markdown 檔 → commit → push → 等一兩分鐘就上線了。

> 這篇文章被設為置頂（front matter 的 `pin: true`），之後不需要置頂時把那一行刪掉即可。
